Hey, to start the app you should first clone the app.
Open terminal and type 

```bash
npm install
npm run start
```

Scan the QR code with Expo Go or press `i` for the iOS simulator.

## What was built

- Task list screen with completion counter
- Add new task (title + optional description)
- Mark tasks complete / incomplete
- Delete task with confirmation
- Task detail screen
- Input validation (min 3 characters, character counter, inline error)
- Fetch tasks from [dummyjson.com/todos](https://dummyjson.com/todos)
- Search tasks by title
- Filter by status (All / Active / Done)
- Empty states per filter
- Pull to refresh
- Dark / light mode (follows system, manual toggle in header)
